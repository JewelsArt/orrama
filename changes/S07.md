## What the client must call (AI-006, for R12's Ask panel)
- **Stop:** `useChat().stop()`. It aborts the `/api/ai/ask` fetch; the server sees the response close before it finished and aborts the run — the model call in flight is cancelled and no later step or tool call runs. No extra endpoint.
- **Closing the panel / unmounting:** call `stop()` in the panel's unmount cleanup (`useEffect(() => () => stop(), [stop])`). Navigating away closes the fetch too.
- **Deadline:** after `BASALT_AI_TIMEOUT_MS` (default 120 s) the run is stopped and the stream carries an `error` part, `"The agent did not finish within 120 s, so it was stopped."` — `useChat` puts it in `error`, so show `error.message` like any other Ask error. A run the client stopped ends with a plain `abort` part (nothing to show).
- **AI-012** (R12): send the open note as `contextNoteId` in the transport body (`DefaultChatTransport({ body: () => ({ contextNoteId }) })` or `prepareSendMessagesRequest`); the server branch is unchanged and still ACL-checked. `search_vault` / `read_note` results now carry `id` and `path`, which helps resolve `[[Title]]` citations.
