## Jules's answer (7 Nov 2026)

- **D13, the secret key in a backup:** the recommended one, **left out**. A lost zip opens no mail
  password, AI key, ChatGPT sign-in, calendar feed or webhook secret. Restored on the same computer
  they open; on another one they are left out of the restored database and Settings asks for them.

## Built

- **Server: Back up now and Restore** (`f828570`). `backup.ts` + `backupZip.ts` (zip writer and
  reader on node:zlib, no new dependency) + `routes/backup.ts`; export's work moved to
  `exportData.ts` and the sealed-column list to `encryptedColumns.ts` (the app bundle refuses modules
  that run themselves). The zip: `README.txt`, `backup.json`, `basalt.db` (SQLite backup API,
  consistent under writes), `export.json`, `notes-folder.json`, `notes/…` (no `.git`, links not
  followed). Restore: upload → look → stage in `<data>/restore-pending/` (notes into the chosen
  folder, never one with files without `replace`; database upgraded, old sessions ended, unreadable
  secrets left out, a session for the owner) → in-place restart → `applyPendingRestore` before the
  database opens (the replaced one kept as `backups/basalt-before-restore-<time>.db`).
- **Export** (same commit): `notes-folder.json` copied; restore text "Quit Orrama…", no launchctl;
  `pnpm --dir apps/server export` unchanged for Jules.
- **Web** (`3f7ab23`): Settings → Notes → Back up (Back up now: folder chooser in the app, download
  in a browser; name, size and where after; Restore from a backup… in a dialog, hidden where the
  folder is fixed). `door/RestoreBackup.tsx`, and first run's "I have a backup" under the account
  form (`Setup.tsx`).
- **Windows uninstall** (`43c5672`): `src-tauri/windows/hooks.nsh` + `installerHooks`.
  `/DELETEAPPDATA` ticks Tauri's "Delete the application data" for a silent uninstall; with it ticked
  (never on `/UPDATE`) the Credential Manager entry `server secrets.com.orrama.desktop` goes too.
  `install-check.mjs --installer` now uninstalls with the flag and checks data folder and credential
  gone, notes kept. A tag's draft release carries `.github/release-notes.md`.
- **Restore's suggested folder** (`b040f9f`): a new `Orrama (restored <date>)` beside Orrama's own
  when that one has files.
- **The install guide**: `docs/install.md`, pictures listed in `docs/install/README.md`; short
  version `.github/release-notes.md`.

## Not proved / needs Windows or Jules

- **Windows** (only a runner can): the hook's NSIS compiles, the silent uninstall with
  `/DELETEAPPDATA` removes `%LOCALAPPDATA%\com.orrama.desktop` and the credential, the notes stay.
  After the integrator pushes: `gh workflow run release.yml --ref main -f version=0.1.0`. Green =
  the "install, run, stop, uninstall with the app data (the notes stay)" step prints "the app's data
  folder is gone", "its Credential Manager entry is gone", "the notes folder and its note are still
  there", "Install check passed." (~40 billed minutes; delete the test draft after.)
- **In the app window, by hand (Jules, ~3 min):** `open -n <worktree>/apps/desktop/src-tauri/target/release/bundle/macos/Orrama.app --env HOME=~/basalt-scratch/2F/app/home --env ORRAMA_DATA_DIR=~/basalt-scratch/2F/app/data --env ORRAMA_DEFAULT_NOTES_DIR=~/basalt-scratch/2F/app/notes`;
  make an account, Start empty; Settings → Notes → Back up now → the folder chooser opens → pick
  `~/basalt-scratch/2F/app` → the line says the zip's name and size. Then Restore from a backup… →
  Choose the backup… → the file chooser opens (WKWebView's `<input type=file>`) → pick that zip →
  its account and notes are named. Quit. The browser pane can't drive native choosers; everything
  after them was proved above.
- **Mac screenshots for the guide**: the Gatekeeper warning only shows for a copy the Mac knows was
  downloaded. Download the release .dmg in a browser (or ask before a new macOS user account), then
  follow docs/install.md "On a Mac" and save the three pictures named in docs/install/README.md.
- Windows pictures: on the first Windows run (VM or friend's PC).
- No ZIP64: a backup stops at 65,535 files or 4 GB, with a sentence. Follow-up if a friend's vault
  is that big.
