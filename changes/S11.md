## Changelog lines (user-facing, for [Unreleased] → Fixed / Security / Internal)
Fixed
- The install guide's quickstart works: it sets the two secrets the server needs before starting it.
- `pnpm --dir apps/server dev` and `seed` use their own folder (`apps/server/data-dev`) and port (4627), so they can never open or replace the live database; `seed` refuses a vault that already holds notes.
- Docker self-host: the container starts on a fresh Linux host (it no longer crash-loops on a root-owned `./data`), reports its health, and is less than half the size.
- The desktop app no longer shows whatever happens to answer on port 4623: until Basalt's server answers, it shows "Basalt isn't running".
- On Windows, the vault's own CLAUDE.md is no longer indexed and stamped, and `pnpm dev` starts.
- A schema upgrade that fails stops the server with the statement that failed, instead of starting and failing later on a missing column.

Security
- Docker publishes the server on this machine only (127.0.0.1); reaching it from elsewhere goes through Tailscale or a proxy (INSTALL.md).
- `export.json` no longer contains webhook URLs (a Slack or Discord hook URL is its credential): only the host and a four-character hint.
- Personal data removed from source comments, the demo seed and CLAUDE.md (a history rewrite follows after the audit).
- CI actions are pinned to commits and the workflow token is read-only.

Internal
- CI also runs on macOS for pushes to sep-2026-redesign, builds and boots the Docker image, lints the web app, reports `pnpm audit`; `desktop.yml` checks the Tauri crate; `windows.yml` runs the suite on Windows by hand.
- `pnpm typecheck` re-runs when an upstream package changes (no stale cache pass before `pnpm ship`).
- `pnpm ship` succeeds only when a new server process reports the build it just made.
- The launchd plist in `scripts/` is a complete template; the web build ships third-party licence notices; `tsx` is a production dependency; Node types are 22.
- ESLint with the React hooks rules (`pnpm lint`).

Upgrading
- None for the running Mac. Optional: the installed `~/Library/LaunchAgents/dev.basalt.server.plist` may switch its program to node as the template does (pnpm also passes SIGTERM on macOS, so nothing breaks if it stays).

  `continue-on-error: true` from the `audit` job in `.github/workflows/ci.yml`.

  register the push trigger. This branch is the first change to ci.yml: the next push of it
  should start a run. If it does not, it is a repository setting for Jules (Settings →
  Actions), not code.
