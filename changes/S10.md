## Changelog lines (user-facing, for [Unreleased] → Fixed / Security / Internal)
- Fixed: a note with a stray `%` in a markdown link (`growth%.png`, `Budget 100% final.pdf`) vanished from the index and could not be saved; it is indexed and saves normally.
- Security: an `#only/<team>` restriction is kept when the front matter has a YAML error (e.g. an unquoted colon in the title), uses `tags: a, only/x` or `tag:`, or follows a one-line ```` ```js``` ```` or an indented ```` ``` ````; a restriction that cannot be read limits the note to owners instead of opening it.
- Security: a `/regex/` in the life-area rules note can no longer freeze the server (it runs in a matcher that takes time linear in the text; backreferences and lookaround are not supported and are ignored).
- Fixed: front-matter `tags: a, b` (or `a b`), `tag:`, `aliases: A, B` and `alias:` are read like Obsidian reads them.
- Fixed: notes with Windows (CRLF) line endings show their tasks and headings, and task and section edits keep CRLF.
- Fixed: tasks, tags and headings inside nested code fences (a ```` ``` ```` example inside `~~~` or ```` ```` ````) are no longer indexed.
- Fixed: checkboxes in `*`/`+` bullets, numbered lists (`1.`, `1)`) and callouts/blockquotes are tasks, as in Obsidian.
- Fixed: `[[Note\|alias]]` inside a table links to Note; a `[[link]]` inside inline code is no longer a link.
- Fixed: life-area rules with a `/…/g` regex or a comma inside a regex categorise correctly.
- Fixed: the Dashboard's "Booked" hours and agenda count every block in your calendar, including blocks on tasks without an @mention.
- Fixed: "Plan my week" no longer proposes work inside subscribed-calendar events that cross midnight or began before the week.
- Fixed: Planning's at-risk flags no longer treat your @-mentioned and unmentioned tasks as two people working in parallel.
