# 1G: Money in screens

Stage 1, wave 1. Branch `stage1/1G-money` from `sep-2026-redesign` (e1f7da2).

## Built
- Core: one writer per ledger table, beside its parser (`table.ts` generic `readLedgerTable`,
  `changeRow`, `removeRow`, `moveRow`, `tableHead`; bound in `subscriptions.ts`, `spending.ts`,
  `ownAccounts.ts`, `payslip.ts`), `fileShopUnder` for "put this shop in…", `typedPayslip`. A row is
  named by its index among the ledger's rows, its name cell and the version of the tables it was read
  at (a hash of the tables' lines only, so prose around them may change); any other change to the
  tables since is a 409. Only that line is rewritten; unknown columns, unreadable rows, CRLF and every
  other byte stay; a change that changes no cell changes no byte. Parsers gained `line` on each item
  (test pins the whole old reading). (commit 1)
- Server (`routes/finance.ts`, one section): `POST /api/finance/:ledger` (subscriptions, income,
  payslips, categories, own-accounts) makes the ledger note on the first add
  (`02-Areas/finance/<Name>.md`, tagged, with the header; create-only through the store; a tagged note
  with no table gets one); `PATCH`/`DELETE /api/finance/:ledger/:index` with `{version, name}`;
  `POST /api/finance/categories/:index/move`; `POST /api/finance/categories/shop`. A payslip upload
  with no payslips note makes it. `GET /api/finance` sends `tables`; the merchant answer sends
  `filing` (its category, or the commitment / own account that keeps it where it is). (commit 2)
- Web (commit 3):
  - one sheet for a commitment or income line (`money/LineSheet.tsx`): add, or change name, amount,
    all eight rhythms, next date, note; remove behind a Confirm. Opens from Add on Subscriptions,
    Income and the overview tiles, from each row, from "Fix it" on an unreadable row, from "Looks
    recurring → Add it" (prefilled; it no longer writes at once) and from Today's New menu
    (`today/AddMoneyRow.tsx` is now that sheet, same name and props).
  - Categories sheet (`money/Categories.tsx`): add, rename, remove, reorder with ↑/↓ (the colour each
    gets is shown), each category's words as chips you add and remove. Opens from Spending's "Edit
    categories" (was "Edit the rules →", which opened the note) and from a category page's "Change",
    under the sentence that says which words bring shops in.
  - Put a shop in a category (`ShopMove`): from the shop's page ("In Groceries · Put it in another
    category") and from each shop row on a category page; the dialog says "Every HEMA row moves from
    Shopping to Groceries, in every month." before it moves. A shop a commitment claims, or an own
    account, says so and offers no move.
  - Own accounts (`money/OwnAccounts.tsx`): "Your own accounts" on the Savings page, with what a move
    means; add, change words, remove in a sheet. The month page's "moved out" sentence links there.
  - Payslips (`money/PayslipSheet.tsx`): "Add a payslip", every filed payslip opens to change or
    remove, a PDF kept but not read is listed with "Type the figures", and the upload's notice offers
    the same.
  - Sentences that taught tables, tags or folders are gone from Money ("Add rows to the note tagged
    …", "02-Areas/finance/files", "Stored …, but the figures were not filed: no note tagged
    #payslips"). "Open the note" stays as a quiet link under each list.
