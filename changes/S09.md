## CLAUDE.md changes to apply (exact text, and where)
- "Conventions & gotchas", the safeFetch bullet: after "every resolved address public (checked in the socket's own `lookup`, so DNS rebinding is caught)," add: "IPv6 ranges that wrap or reach an IPv4 address (IPv4-compatible, IPv4-translated, NAT64, 6to4, Teredo) refused whole,"
- "Conventions & gotchas", new bullet after the safeFetch one:
  "- **Untrusted input is read within a budget, off the event loop where it can't be bounded.** Office files go through `zip.ts`: every part inflated against `DOCX_CAPS`/`XLSX_CAPS` (an XML-part cap and a total) before mammoth or exceljs sees the bytes — the zip's declared sizes are never believed; over a cap is a 413, unreadable a 422. A .pptx reads each slide once and shares one XML budget (`SLIDE_CAPS.xmlBudget`). ICS expansion jumps to the window and stops at `MAX_EXPAND_STEPS` per feed (ics.ts). A payslip PDF is read in a worker (`pdfText.ts`, plain `.mjs`) with a page cap and a time limit: pdf.js parses a page in one synchronous stretch that no main-thread timer can interrupt. Anything new that parses a user's file or feed gets a cap, and a worker if its cost can't be capped."
- "Conventions & gotchas", the "A create never replaces" bullet: append "A `.md` uploaded into a project's files is a note and is created through `store.write` like New note (routes/projects.ts), never stored as bytes the watcher would index past the ACL."
- "Releases" (or "Conventions"), new line: "**Dependencies are audited**: `pnpm audit --prod --audit-level=high` must pass; an advisory judged unreachable goes into `auditConfig.ignoreGhsas` in pnpm-workspace.yaml with its reason, and comes out when the package is bumped past the fix. Pick a fixing release at least a week old when one exists (`--config.minimum-release-age`)."

- @fastify/static 8 → 10 (4 advisories, not reachable): Jules kept it on 8 (the 10.x `setHeaders` change touches main.ts's static cache headers). Allow-listed with the reason.
- vitest 3 → 4 (tinypool ×2 critical, @vitest/mocker; dev only): Jules kept it for its own task. Allow-listed.
- The CI step for the audit gate and a Dependabot/Renovate config live in `.github/`, which is S11's (OPS-004): the command is `pnpm audit --prod --audit-level=high`.
- mammoth still converts on the main thread, within INP-004's caps (worst measured at the cap: 1.2 s, 1.1 GB, the loop held ~0.5 s at a time). The worker pattern from pdfText.ts would move it; not done here.
- Lead "mail-iframe reverse-tabnabbing in WKWebView": not real. Probed with a WKWebView and a real (synthesised) click on the audit's tabnab page: Basalt's shell sets no `on_new_window`, so wry's UI delegate returns no web view, WebKit opens nothing and the attacker page is never requested. With popups allowed (control), the popup gets an opener but navigating Basalt through it throws SecurityError. Side effect worth a follow-up: in the desktop app a link in a mail opens nothing at all; an `on_new_window` that hands the URL to the default browser and denies the popup would fix that (Rust, needs a Tauri build to verify).
- The lockfile already held entries under a week old from other sessions (happy-dom 20.14.6, @babel/runtime 7.29.10), so a 7-day `minimumReleaseAge` can't be set for the repo yet; worth setting once they age.
- `test/new-folder-watch.test.ts` timed out once (5 s) in a full run at load average 176 with other sessions running; it passes alone (3/3). Not touched.
