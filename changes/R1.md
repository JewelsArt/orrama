## Built
- `GET /api/settings/server` (new `routes/settings.ts`): the notes folder said as `~/…`, the note count, the version; owners only. A schema for `GET /api/members`. Contract rows for both (3ea9b34)

- Connections, This device (now says whether a passcode is set), Signed in, Developer (with the MCP address) (b6ccd29)
- The colour editor is a sheet in the overlay stack instead of a dialog, so its Delete confirm goes over it instead of replacing it and losing the edits (b6ccd29)
- Settings' ↻ glyph replaced with the `repeat` line icon (R0 hand-off) (b6ccd29)

## Board vs app: differences left on purpose
- "What Orr may do" switches (draft mail, suggest links, propose plans): left out. The app has no such settings and all three are always-ask (Jules, 11 Oct).
- The AI state line has no Test button and no "last answer 10:32": no endpoint (Jules, 11 Oct).
- The API key shows "A key is stored on this server", not dots with the last four: the server never sends any part of the key.
- Company offers Anthropic and Google (Gemini); the board also says OpenAI. The server has no "openai" provider; OpenAI goes through OpenAI-compatible. Model is a text field for key providers (no model list exists); a select for the ChatGPT plan.
- The footer says "Orrama 0.1.0 · reading 13 notes in ~/…" from the package version, not "2026.10".
- Only Orr & AI is drawn on the desktop board; the other seven sections follow its patterns (header with mark and line, white box, boxed choices, state line, savebar). Orr stands in Orr & AI's header (think) and your Orr in You's; no other section has a figure.
- Phone list rows say "This device", not "This phone": the app can't know it's a phone. The board's "Settings used to have no door…" line is board commentary, not drawn.
- Phone Back is the shell's chevron, not "‹ More".
- No notifications row in This device: the app has none.
- Re-read the folder: not built. No server action exists and the watcher keeps the index live; a reindex endpoint would touch `vaultStore.ts` (S01/S04).
- The colour editor keeps its Finance-style preview and the "Basalt" brand slot label (`palette.ts`, R0's, and `vised-*` is "restyled through tokens only" per §6); it is now a sheet from the right.
- The username (`@jules`) is no longer shown; email is.
