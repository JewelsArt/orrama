## Board vs app: differences left on purpose
- No board for these controls; they reuse Dialog, Sheet, Menu, Row, SearchField, the project
  page's row-with-⋯ pattern and 1C's RenameNoteDialog.
- **Name is not in the Edit sheet** although the prompt listed it: renaming is the page's ⋯ →
  Rename… (1C's dialog says which links follow and offers Undo). One way per place; a rename can
  be refused (a name taken) independently of the facts.
- The company field inside New person is an in-place search, not a second dialog: a dialog
  replaces any other dialog (overlays.tsx, one of a kind).
- Works at keeps its own control (facts row + picker dialog), not a field in the Edit sheet,
  so Orr noticed's fix opens exactly that picker.
