`docs/install.md` shows these. Each is a real screenshot, light mode, the window only, PNG,
about 1,000 pixels wide. None is taken yet (7 Nov 2026).

| File | What | Taken |
|---|---|---|
| `mac-1-not-opened.png` | "Orrama" Not Opened, Apple could not verify… (Done, Move to Bin) | to take on this Mac, from a downloaded copy of the .dmg |
| `mac-2-open-anyway.png` | System Settings → Privacy & Security, "Orrama" was blocked…, Open Anyway | to take on this Mac |
| `mac-3-open.png` | the last "Open Anyway" after the password | to take on this Mac |
| `win-1-smartscreen.png` | Windows protected your PC, with More info | to take on the first Windows run |
| `win-2-run-anyway.png` | the same, after More info: Run anyway | to take on the first Windows run |
| `win-3-uninstall.png` | the uninstaller, with Delete the application data | to take on the first Windows run |

The Mac warning appears only for an app the Mac knows came from the internet: download the
.dmg from the release page (or a browser), never copy the built app across.
